:::user
서울로 AI는 어떤 프로젝트야?
:::

:::assistant
**선택 몇 번으로 시간표까지 완성된 서울 여행 코스를 만들어 주는 LangGraph RAG 에이전트 서버**입니다.

기존 서울로는 Next.js 기반 풀스택이었는데, LangGraph와 RAG 생태계를 쓰려면 Python이 필요했습니다. 그래서 "나만의 코스" 기능만 떼어내 별도 AI 서버로 만들었습니다. 실제 서울 속 장소의 다양성과 더 정교한 맞춤 선택 구조, 자연어 입력을 얹는 게 목표였습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2026-06 ~ 2026-09 |
| 역할 | AI 엔지니어 (에이전트 파이프라인 · RAG · 배포) |
| 형태 | 카카오테크 부트캠프 개인 프로젝트 |
| 서비스 | [seoulro.site](https://seoulro.site/) |
| 프론트 | [seoulbidata/strangemap](https://github.com/seoulbidata/strangemap) |
:::

:::user
어떤 기능이 있어?
:::

:::assistant
**사용자 선택에 따라 완성되는 코스** — 동반·목적·위치·시간·식사 수·인원·일수·혼잡도 여부를 고르면 장소 선정부터 방문 시각까지 서버가 확정합니다. `"저녁에 연인이랑 홍대에서 야경"` 처럼 자연어 한 줄로도 같은 결과가 나옵니다.

**"왜 이 장소인가"를 함께 추천** — 각 스톱에 선정 이유(`reason`)와 그곳에서 할 일(`activities`)이 붙습니다. 실제 시설·볼거리(`highlights`)를 근거로 삼아서, "공원이라 산책하기 좋아요" 같은 일반적인 답변이 나오지 않게 막았습니다.

**실행 가능한 시간표** — 방문 순서를 순열 전수 탐색으로 최적화하고, 남은 시간 예산을 체류시간 비율대로 나눠 방문 시각과 이동수단까지 확정합니다. 시간 산술은 LLM에게 맡기지 않습니다.

**예상 혼잡도 반영** — 방문 시각 기준 서울시 예상 혼잡도, 진행 중인 문화행사, 주변 식당 정보를 붙입니다. 현재 혼잡도가 아니라 *방문할 시간대의* 예보를 씁니다.

**같은 조건이면 같은 코스** — 시드를 칩 + 자유입력 해시로 잡아 재현 가능하게 두고, `seed`를 실어 보내면 "다시 만들기"에서 다른 코스가 나옵니다.

**생성 과정이 보이는 스트리밍** — SSE로 노드별 진행 상황(`progress`)을 흘려서, 지금 뭘 하고 있는지 UI가 그대로 보여줍니다.
:::
